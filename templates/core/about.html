Core Design Principles

Strict Server-Side Evaluation

Unlike basic quiz scripts, examination question payloads sent to the browser NEVER contain the correct answer option or solution matrices. Evaluation occurs strictly on the server upon authenticated submission.

Continuous State Synchronization

Candidate responses are continuously persisted. If the client experiences network packet loss, power failure, or machine reboot, resumption occurs without loss of work or timer discrepancies.

Intelligent PDF Compiler

Combines PyMuPDF vectorized layout analysis with Tesseract OCR for scanned papers. Preserves mathematical equations and formulas, extracts diagrams, and provides an editable preview workspace.

Configurable Freemium Business Model

Integrated Razorpay billing engine supporting initial free test evaluation, premium test access controls, recurring plans, coupons, and secure server-verified webhooks.

Technology Stack Details

  • Backend Framework Python 3.12 + Django 5.2 LTS
  • Primary Database PostgreSQL (psycopg v3) / SQLite dev fallback
  • Frontend Presentation HTML5, Bootstrap 5.3, JavaScript ES6+
  • Document & OCR Engines PyMuPDF (fitz) + Tesseract OCR
  • Asynchronous Jobs & Queue Celery + Redis Broker
  • Commercial Payment Gateway Razorpay (UPI, Netbanking, Cards)
