Core Design Principles

Strict Server-Side Evaluation

Answers are evaluated on the server; separate keys and explanations are withheld during a test. Original question text or images can themselves contain printed answers, so every source must be reviewed before publication.

Continuous State Synchronization

Answers autosave while connected. Refresh or reconnect resumes the same active attempt and original server deadline; unsent changes can be lost if the connection is interrupted or time expires.

Intelligent PDF Compiler

Uses local PyMuPDF layout analysis and Tesseract OCR when configured. Original question images and an editable preview help you review formulas, tables and diagrams; extraction can miss or misread content.

Clear, One-Time Packs

Separate free allowances and one-time packs for PDFs, classrooms and JEE/NEET series. Razorpay integration is test-mode only; real payments are not yet available.

Technology Stack Details

  • Backend Framework Python 3.10–3.14 + Django 5.2 LTS
  • Primary Database PostgreSQL (psycopg v3) / SQLite dev fallback
  • Frontend Presentation HTML5, Bootstrap 5.3, JavaScript ES6+
  • Document & OCR Engines PyMuPDF (fitz) + Tesseract OCR
  • Asynchronous Jobs & Queue Celery + Redis Broker
  • Commercial Payment Gateway Razorpay · test mode only
